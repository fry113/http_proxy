# Асинхронный HTTP прокси сервер

Этот проект представляет собой асинхронный HTTP прокси сервер, написанный на C++ с использованием библиотеки Boost.Asio. Прокси сервер предназначен для перенаправления HTTP-запросов от клиентов к целевым серверам и возврата ответов обратно клиентам.

## Особенности:
- Асинхронная обработка запросов для высокой производительности.
- Поддержка протокола HTTP/1.1.
- Использование библиотеки Boost.Asio для работы с сетью.
- Легкая настройка и интеграция в различные проекты.

## Сборка проекта и запуск тестов

Данный репозиторий использует следующие инструменты:

- **cmake** — генератор систем сборки для C и C++.
- **VS Code Dev Docker container** - Docker контейнер, который содержит полностью настроенное окружение для выполнения задания.

### Команды для сборки проекта

Используйте `F5` для выполнения следующих шагов:
- Создания папки `build`
- Вызова `cmake` команд для запуска процесса сборки
- Запуска `lldb` отладчика

### Команды для запуска приложения

```bash
cd build

./AsyncHttpProxy 5555 &

python3 -c 'print("HTTP/1.1 200 OK\r\nContent-Type: text/html\r\nContent-Length: 4096\r\n\r\n" + "A"*4096, end="")' | nc -l 127.0.0.1 -p 8000 &

wget -e use_proxy=yes -e http_proxy=127.0.0.1:5555 127.0.0.1:8000
```

### Команды для запуска отладчика

В Visual Studio Code настройки параметров для запуска отладчика находятся в файле .vscode/launch.json. Поскольку в этом файле для запуска приложения уже есть одна конфигурация `Launch *`, то для запуска отладчика достаточно нажать F5 или открыть окно Run and Debug комбинацией клавиш `Ctrl+Shift+D`.

### Запуск тестов

Чтобы запустить тесты, используйте расширение `C++ TestMate` в Visual Studio Code. Вот шаги для настройки и запуска тестов:

1. **Установите расширение C++ TestMate:**
   - Откройте VS Code.
   - Перейдите в раздел Extensions (Расширения).
   - Найдите и установите `C++ TestMate`.

2. **Настройте конфигурацию тестов:**
   - Откройте файл `.vscode/launch.json`.
   - Добавьте или убедитесь, что есть конфигурация для запуска тестов.

3. **Запустите тесты:**
   - Нажмите `F5` или откройте окно Run and Debug комбинацией клавиш `Ctrl+Shift+D`.
   - Выберите конфигурацию тестов и запустите их.
